One paragraph

Volume is a workout logger built on one idea: your session is one number. Every set is reps × weight; they sum to a volume score; the app's only job is remembering it and telling you whether you beat last time. Streaks reward showing up, records celebrate beating yourself — and there is deliberately no coaching, no plans, no social feed, and no account.

The story

Volume was built by a solo developer who got tired of being managed by fitness apps. The insight: progressive overload — do slightly more than last time — is the only mechanism that reliably makes lifting work, and it's fundamentally a memory problem, not a knowledge problem. So the app is a scoreboard, not a coach. Every feature was tested against one rule: facts about the user's log are in; anything that tells the user what to do is out.

Details worth printing

  • Bodyweight sets score their reps — 0 lb never means 0 effort. Warm-ups are saved but never inflate the score.
  • Equal doesn't count as beating; only strictly more does.
  • An unfinished week can never break a streak — users are judged only on completed weeks, so the app never guilt-trips on a Monday morning.
  • Backdate a forgotten workout and every streak, record and chart recalculates as if it was always there — nothing in the app is a cached aggregate.
  • Switching lb/kg converts every historical score instantly, for the same reason.
  • No cardio, on purpose: "one rep of treadmill" would make the number meaningless.
